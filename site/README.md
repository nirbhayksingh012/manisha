# Manisha Mishra — Portfolio
Static site, no build step. Open `index.html`, or upload this folder to Netlify / Vercel / GitHub Pages.
Libraries (bundled in /vendor): GSAP + ScrollTrigger, Lenis, Swiper, vanilla-tilt, GLightbox.
`<wise-text>` is a custom text tag (modes: split, words, type, rotate) defined in assets/main.js.
Edit text in index.html; images are in assets/img.
